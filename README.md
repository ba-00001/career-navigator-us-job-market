# Career Navigator U.S. Job Market

Data analytics project for ISM 4402 focused on the U.S. entry-level job market by sector.

## Project Focus
This project supports the idea of a LinkedIn-style Career Navigator by analyzing where early-career workers can find strong opportunities across U.S. sectors. The planned analysis compares sectors and occupations using employment, projected growth, openings, wages, education requirements, and work activities.

## Repository Structure
- `docs/` project drafts and planning notes
- `data/raw/` source files downloaded from official sites
- `data/processed/` cleaned analysis-ready files

## Main Data Sources
- U.S. Bureau of Labor Statistics Employment Projections
- U.S. Bureau of Labor Statistics OEWS wage tables
- U.S. Bureau of Labor Statistics State and Area Employment tables
- U.S. Bureau of Labor Statistics CPS labor-force characteristics tables
- O*NET Work Activities

## Current Status
This repo currently includes the initial project write-up and Tableau build plan. Some BLS files may need to be downloaded manually in a browser because automated retrieval can be blocked by BLS anti-bot protections.
